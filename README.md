# حساب‌یار

نرم‌افزار فارسی مدیریت موجودی، قیمت‌گذاری و فروش برای فروشگاه‌ها و کسب‌وکارهای کوچک.

حساب‌یار با معماری کلاینت–سرور کار می‌کند:

- نسخهٔ سرور روی رایانه‌ای اجرا می‌شود که دیتابیس روی آن قرار دارد.
- نسخهٔ فروشنده از طریق شبکهٔ داخلی به سرور متصل می‌شود.
- هر دو نسخه از یک دیتابیس مرکزی استفاده می‌کنند.
- تغییرات فاکتور و موجودی به‌صورت دوره‌ای بین نسخه‌ها همگام می‌شود.

> رابط کاربری برنامه فارسی و راست‌به‌چپ است.

## امکانات

### نسخهٔ سرور

- نمای کلی فروش و موجودی
- ثبت، ویرایش و حذف کالا
- مدیریت موجودی
- ثبت قیمت خرید و قیمت دلاری کالا
- محاسبهٔ ارزش موجودی و اختلاف قیمت
- صدور و اصلاح فاکتور
- کاهش خودکار موجودی پس از فروش
- نمایش و چاپ فاکتور
- چاپ برچسب QR کالا
- تنظیم نرخ دلار به‌صورت دستی یا از طریق API
- انتخاب واحد نمایش قیمت‌ها: ریال، تومان یا دلار
- پشتیبان‌گیری محلی و ارسال اختیاری به تلگرام

### نسخهٔ فروشنده

- اتصال به سیستم مرکزی با وارد کردن IP
- صدور فاکتور فروش
- جست‌وجوی کالا بر اساس نام یا کد
- انتخاب تعداد، قیمت فروش، مشتری و تخفیف
- اصلاح فاکتور
- مشاهده، جست‌وجو و چاپ سوابق فاکتورها
- انتخاب واحد نمایش قیمت‌ها
- همگام‌سازی خودکار با سرور

نسخهٔ فروشنده به بخش‌های مدیریت انبار، افزودن کالا، تغییر نرخ دلار و پشتیبان‌گیری دسترسی ندارد.

## فناوری‌ها

- Python 3.11+
- FastAPI و Uvicorn
- SQLite
- PyWebView
- HTML/CSS/JavaScript
- PyInstaller برای ساخت فایل اجرایی ویندوز

## ساختار پروژه

```text
accounting/
├── app/
│   ├── main.py              # API و منطق نسخهٔ سرور
│   └── static/
│       └── index.html       # رابط نسخهٔ سرور
├── seller_main.py           # API واسط نسخهٔ فروشنده
├── seller_static/
│   └── index.html           # رابط نسخهٔ فروشنده
├── run_app.py               # اجرای نسخهٔ سرور
├── run_seller.py            # اجرای نسخهٔ فروشنده
├── backup.py                # منطق پشتیبان‌گیری
├── requirements.txt
├── build_exe.ps1            # ساخت EXE سرور
└── build_seller_exe.ps1    # ساخت EXE فروشنده
```

## نصب برای توسعه

در PowerShell اجرا کنید:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## اجرای نسخهٔ سرور

برای اجرای برنامهٔ دسکتاپ:

```powershell
python run_app.py
```

برای اجرای API در حالت توسعه:

```powershell
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

نسخهٔ سرور روی آدرس زیر در دسترس خواهد بود:

```text
http://127.0.0.1:8000
```

## اتصال نسخهٔ فروشنده

ابتدا نسخهٔ سرور را روی رایانه‌ای اجرا کنید که دیتابیس روی آن قرار دارد.

سپس نسخهٔ فروشنده را اجرا کنید. در پنجرهٔ ابتدایی، IP رایانهٔ سرور را وارد کنید:

```text
192.168.1.20
```

همچنین می‌توانید پورت را نیز وارد کنید:

```text
192.168.1.20:8000
```

هر دو رایانه باید به یک شبکهٔ داخلی مشترک متصل باشند.

### پیدا کردن IP سرور در ویندوز

روی رایانهٔ سرور دستور زیر را اجرا کنید:

```powershell
ipconfig
```

مقدار `IPv4 Address` مربوط به کارت شبکهٔ فعال را در نسخهٔ فروشنده وارد کنید.

## تنظیم Windows Firewall

اگر نسخهٔ فروشنده به سرور وصل نمی‌شود، پورت `8000` را روی رایانهٔ سرور برای شبکهٔ خصوصی باز کنید:

```powershell
New-NetFirewallRule `
  -DisplayName "Hesabyar Server 8000" `
  -Direction Inbound `
  -Protocol TCP `
  -LocalPort 8000 `
  -Action Allow `
  -Profile Private
```

این دستور را فقط روی رایانهٔ سرور اجرا کنید.

## ساخت فایل اجرایی ویندوز

### نسخهٔ سرور

```powershell
.\build_exe.ps1
```

خروجی:

```text
dist\Hesabyar.exe
```

### نسخهٔ فروشنده

```powershell
.\build_seller_exe.ps1
```

خروجی نسخهٔ فروشنده بر اساس تنظیم فعلی اسکریپت:

```text
dist\HesabyarSellerEdit.exe
```

در صورت قفل بودن فایل خروجی توسط ویندوز یا آنتی‌ویروس، نام دیگری برای ساخت EXE انتخاب کنید.

## دیتابیس

دیتابیس اصلی نسخهٔ سرور در مسیر زیر ذخیره می‌شود:

```text
%USERPROFILE%\Documents\Hesabyar\accounting.db
```

نسخهٔ فروشنده دیتابیس مستقل ندارد و اطلاعات را از API نسخهٔ سرور دریافت می‌کند.

## واحد پول

مقادیر مالی در دیتابیس به ریال ذخیره می‌شوند، اما واحد نمایش قابل انتخاب است:

- ریال
- تومان
- دلار

واحد پیش‌فرض نسخه‌های جدید «تومان» است و انتخاب کاربر در همان سیستم ذخیره می‌شود.

## API اصلی

پس از اجرای سرور، مستندات تعاملی API در آدرس زیر در دسترس است:

```text
http://127.0.0.1:8000/docs
```

مهم‌ترین مسیرها:

```text
GET    /api/dashboard
GET    /api/products
POST   /api/products
PUT    /api/products/{id}
DELETE /api/products/{id}

GET    /api/invoices
POST   /api/invoices
PUT    /api/invoices/{id}

GET    /api/exchange-rate
POST   /api/exchange-rate
POST   /api/exchange-rate/refresh
GET    /api/exchange-rate/settings
POST   /api/exchange-rate/settings
```

## تنظیمات محیطی

در صورت نیاز فایل `.env` را در ریشهٔ پروژه ایجاد کنید:

```env
TELEGRAM_BOT_TOKEN=
```

- `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام برای ارسال پشتیبان

نمونهٔ پاسخ قابل قبول برای نرخ دلار:

```json
{"usd": {"value": "206200"}}
```

یا:

```json
{"rate": 206200}
```

## پشتیبان‌گیری

پشتیبان‌گیری از دیتابیس توسط نسخهٔ سرور انجام می‌شود و فایل‌ها در پوشهٔ زیر قرار می‌گیرند:

```text
backups/
```

پیشنهاد می‌شود فایل‌های پشتیبان روی یک دیسک یا فضای جداگانه نیز نگهداری شوند.

## رفع خطاهای رایج

### نسخهٔ فروشنده به سرور وصل نمی‌شود

موارد زیر را بررسی کنید:

1. نسخهٔ سرور در حال اجرا باشد.
2. IP درست رایانهٔ سرور وارد شده باشد.
3. هر دو رایانه در یک شبکه باشند.
4. پورت `8000` در Firewall باز باشد.
5. آدرس `http://SERVER-IP:8000/docs` از رایانهٔ فروشنده باز شود.

### اطلاعات به‌روز نمی‌شود

هر دو نسخه تغییرات را به‌صورت دوره‌ای از سرور می‌خوانند. اتصال شبکه را بررسی کنید
### پورت ۸۰۰۰ اشغال است

یک برنامهٔ دیگر از این پورت استفاده می‌کند. آن برنامه را ببندید یا پورت نسخهٔ سرور و نسخهٔ فروشنده را به‌صورت هماهنگ تغییر دهید.

## نکات امنیتی

- برنامه را فقط روی شبکهٔ داخلی قابل اعتماد اجرا کنید.
- پورت `8000` را روی اینترنت عمومی باز نکنید.
- از دیتابیس به‌صورت منظم پشتیبان بگیرید.
- برای استفادهٔ اینترنتی، احراز هویت، HTTPS و محدودسازی دسترسی API لازم است.
