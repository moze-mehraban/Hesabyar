# حساب‌یار انبار

نرم‌افزار وب فارسی برای مدیریت موجودی، قیمت خرید ریالی، ارزش‌گذاری دلاری و محاسبه معادل ریالی کالاها.

## نسخه فعلی

این نسخه یک MVP محلی است:

- SQLite برای ذخیره‌سازی محلی
- API با FastAPI
- رابط کاربری فارسی و راست‌به‌چپ
- صفحات جدا برای نمای کلی، انبار، افزودن/ویرایش کالا، صدور فاکتور و سوابق فاکتورها
- انتخاب واحد نمایش قیمت‌ها بین ریال، تومان و دلار بدون تغییر دیتابیس
- نرخ دلار قابل دریافت از API و قابل ثبت دستی
- ثبت کالا، موجودی و قیمت خرید ریالی
- ویرایش کالا با حفظ کد و بارکد
- ثبت فروش و صدور فاکتور
- کاهش خودکار موجودی پس از فروش
- چاپ فاکتور و برچسب کالا
- محاسبه ارزش دلاری/ریالی و اختلاف ارزش فعلی با بهای خرید
- اسکریپت بکاپ روزانه با ارسال اختیاری به تلگرام

## اجرا

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

سپس مرورگر را روی `http://127.0.0.1:8000` باز کنید.

## اتصال دستگاه‌های دیگر در شبکه داخلی

برنامه از طریق پورت `8000` روی شبکه داخلی قابل دسترسی است. IP کامپیوتر میزبان را با اجرای `ipconfig` پیدا کنید؛ برای مثال اگر IP برابر `192.168.1.20` بود، از موبایل یا کامپیوتر دیگرِ همان شبکه این آدرس را باز کنید:

```text
http://192.168.1.20:8000
```

کامپیوتر میزبان و دستگاه‌های دیگر باید به یک Wi‑Fi یا شبکه کابلی وصل باشند. در اولین اجرا، دسترسی Python/Uvicorn را در Windows Firewall برای شبکه Private مجاز کنید.

## ساخت فایل EXE ویندوز

بعد از نصب موفق وابستگی‌ها، در PowerShell اجرا کنید:

```powershell
.\build_exe.ps1
```

خروجی در مسیر `dist\Hesabyar.exe` ساخته می‌شود. با اجرای آن، برنامه سرور محلی را روشن می‌کند و مرورگر را باز می‌کند. دیتابیس کنار فایل اجرایی در پوشه `data` ساخته می‌شود.

## تنظیمات

فایل `.env.example` را به `.env` تبدیل کنید و در صورت نیاز مقدارهای زیر را تنظیم کنید:

- `EXCHANGE_RATE_API_URL`: آدرس API نرخ ارز؛ پاسخ JSON ساختار `{"usd":{"value":"206200"}}` یا یکی از کلیدهای `rate`، `price`، `value` یا `usd_irr` را داشته باشد.
- `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام برای ارسال بکاپ
- `TELEGRAM_CHAT_ID`: شناسه چت مقصد بکاپ

اگر API نرخ ارز در دسترس نباشد، آخرین نرخ ذخیره‌شده استفاده می‌شود.

آدرس API را می‌توانید مستقیماً از داخل برنامه در بخش تنظیمات نرخ دلار ذخیره کنید؛ همچنین می‌توان آن را در `.env` با نام `EXCHANGE_RATE_API_URL` قرار داد.

## API

- `GET /api/dashboard`
- `GET /api/products`
- `POST /api/products`
- `PUT /api/products/{id}`
- `DELETE /api/products/{id}`
- `GET /api/invoices`
- `POST /api/invoices`
- `GET /api/exchange-rate`
- `POST /api/exchange-rate`
- `POST /api/exchange-rate/refresh`
- `GET /docs`

## نکته امنیتی

برای استفاده عمومی روی اینترنت، قبل از انتشار باید ورود کاربران، HTTPS، محدودسازی دسترسی API، مدیریت secrets و بکاپ خارج از سرور اضافه شود.
